## Method Summary
Two classification models (Decision Tree and Logistic Regression) were trained to predict song popularity (Spotify Tracks Dataset) and view counts (Spotify & Youtube Dataset), based on audio features such as danceability, energy, and loudness. Model performance was also evaluated using accuracy, precision, recall, and F1 score
